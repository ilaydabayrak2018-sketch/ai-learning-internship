# Yapay Zeka Staj Çalışmaları (AI Learning Internship)

Bu depo, yapay zeka ve veri bilimi staj programı sürecinde gerçekleştirilen teorik dokümantasyonları, pratik kodlama çalışmalarını ve haftalık raporları içermektedir.



## İçindekiler

1. [AI Fundamentals](#1-ai-fundamentals)
2. [Python](#2-python-basics)
3. [Python Practice](#3-python-practice)
4. [Data Science & Exploratory Data Analysis (EDA)](#4-data-science--exploratory-data-analysis-eda)
5. [Presentations](#presentations)
6. [Weekly Reports](#weekly-reports)


##  Dizin Yapısı ve Modüller

### 1. AI Fundamentals
*Klasör: `01_ai_fundamentals/`*
* [01_AI_Ecosystem.md](01_ai_fundamentals/01_AI_Ecosystem.md): Yapay zeka kavramları, makine öğrenmesi, derin öğrenme, veri bilimi ve LLM ekosistemi özeti.

### 2. Python
*Klasör: `02_python/`*
* Python temel veri tipleri, döngüler, fonksiyonlar ve nesne yönelimli programlama (OOP) notları.

### 3. Python Practice
*Klasör: `03_python_practice/`*
* Algoritma pratikleri, veri yapıları alıştırmaları ve veri analizi çalışmaları.

### 4. Data Science & Exploratory Data Analysis (EDA)
- **Klasör:** `04_data_science/`
- `04_data_exploration.ipynb`: Pandas kütüphanesi ile veri keşfi, veri temizleme, eksik değer analizi (`isnull`), özet istatistikler (`describe`, `info`, `value_counts`) ve hedef/öznitelik (feature/target) incelemesi.
- **Klasör:** `datasets/`
- Çalışmalarda kullanılan açık kaynaklı veri setleri (Titanic / Student Performance vb.).

### Presentations
*Klasör: `presentations/`*
* Staj sürecinde hazırlanan proje ve konu anlatım sunumları.

### Weekly Reports
- **Klasör:** `weekly_reports/`
- `Week_01_Report.md`: 1. Hafta — AI Ekosistemi ve Kavram Haritası
- `Week_02_Report.md`: 2. Hafta — Python Temelleri I (Sözdizimi, Veri Tipleri)
- `Week_03_Report.md`: 3. Hafta — Python Temelleri II (Kontrol Akışı, Fonksiyonlar)
- `Week_04_Report.md`: 4. Hafta — Veri Bilimine Giriş, Pandas ve Keşifçi Veri Analizi (EDA)
